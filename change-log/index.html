Version 5.0

⭐ Major Milestone September 26, 2026
5 GB Streaming ZV3 Format ZIP64 Low RAM OPFS
New
5 GB Low-RAM Streaming Engine (ZV3\0): Architected a chunked 4 MB STREAM AEAD (AES-256-GCM) pipeline capable of compressing, encrypting, and decrypting vaults up to 5 GB with strictly bounded heap RAM (< 150 MB) on mobile (Android Chrome, iOS Safari) and desktop browsers.
New
Zero-Buffer Streaming ZIP64 Packager (stream-packer.js): Directly streams unencrypted source files via file.stream() and native CompressionStream('deflate-raw') with 24-byte ZIP64 Data Descriptors (Bit 3), dynamic STORE/DEFLATE evaluation, and an encrypted tail catalog.
Perf
Instant Vault Explorer & Selective Chunk Extraction (stream-unpacker.js): Unlocks and catalogs 1,000+ files from a 5 GB vault in < 100 ms using < 15 MB RAM by reading only the 57-byte container header and encrypted tail manifest; extracts individual files or media streams by decrypting only their required 4 MB chunk span.
Security
Off-Thread Web Worker & Credit Backpressure (crypto-worker.js): Offloads 600,000-iteration PBKDF2-SHA512 key derivation, deflate compression, and AES-GCM chunk processing to a dedicated background worker with zero-copy Transferable buffers and 2-credit (~8 MB) flow control.
New
Multi-Tier Mobile & Desktop Streaming Downloads (stream-saver.js): Implements Tier 1 FileSystem Access API (showSaveFilePicker), Tier 2 Service Worker /_stream_download stream interception, and Tier 3 OPFS disk staging to ensure massive outputs save reliably without hitting in-memory Blob limitations.
Verified
Automated Verification Suite: Added 710 automated unit, integration, and 4-tier E2E tests verifying cryptographic integrity, tamper rejection, memory bounds, and backward compatibility.
