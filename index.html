Why Choose ZevSafe for Offline Folder Encryption?

Zero-knowledge client-side encryption engineered for privacy, speed, and cross-platform portability.

🛡️

100% Client-Side & Zero-Knowledge

All encryption and decryption runs entirely in your browser using the native Web Crypto API. Files, passwords, and keys never leave your device.

🔐

AES-256-GCM Military-Grade Cipher

Authenticated Galois/Counter Mode encryption automatically verifies data integrity and prevents tampering, bit-flipping, and corruption.

⚙️

PBKDF2-SHA512 (600,000 Iterations)

Strengthened key stretching with a 32-byte CSPRNG random salt provides robust resistance against GPU/ASIC brute-force and dictionary attacks.

🗝️

Keyfile Two-Factor Authentication

Enhance security by combining your password with any personal file (image, document, key) as an indispensable second factor.

📦

Full Folder Tree Compression

Smart adaptive packaging compresses text files while using instant STORE mode for pre-compressed videos and photos, maximizing performance.

✈️

Air-Gapped & 100% Offline PWA

Install as a Progressive Web App and operate in complete airplane mode. No network connection or account sign-up is ever needed.

Frequently Asked Questions

Everything you need to know about browser-based zero-knowledge folder protection.

How does ZevSafe encrypt folders without uploading them?
ZevSafe runs 100% inside your browser using the native W3C Web Crypto API. Folders are packaged into an in-memory zip archive, an AES-256-GCM encryption key is derived using PBKDF2-SHA512 (600,000 iterations), and the ciphertext is downloaded directly to your disk. No data is ever transmitted over the network.
Is ZevSafe safe to use offline and air-gapped?
Yes. ZevSafe is a Progressive Web App (PWA) with full offline caching. You can disconnect your Wi-Fi, unplug Ethernet, or use airplane mode. Your files and passwords remain strictly in device RAM.
What encryption standard does ZevSafe use?
ZevSafe employs military-grade AES-256-GCM (Galois/Counter Mode) authenticated encryption, PBKDF2-SHA512 key derivation with 600,000 rounds, a 32-byte cryptographically secure random salt, and an optional physical keyfile second factor.
What is the maximum folder size I can encrypt?
On desktop browsers, ZevSafe can process folders and videos up to 5 GB+ with zero-copy stream architecture. On mobile devices, files up to 2.5 GB are supported. For 25 GB to 100 GB+ datasets, download our 1-click Windows PC Setup toolkit from the navigation bar.
Can I use ZevSafe on my phone or tablet?
Yes! ZevSafe is an installable, 100% offline Progressive Web App (PWA). You can install it directly to your home screen or app drawer on Android, iOS, and desktop with zero sideloading and zero APK files. In your mobile browser, simply tap your browser menu (⋮) and choose "Install app" or "Add to Home Screen". It launches as a full-screen, standalone app with zero network connection required.
