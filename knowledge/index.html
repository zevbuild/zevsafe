Security Invariants & Cryptographic Matrix

Uncompromising guarantees enforced across all 10 ZevSafe services. Every cryptographic decision is verifiable client-side.

Domain / Service Cryptographic Primitives Key Parameters Memory / Network Boundary Adversary Threat Model
01. Core Streaming Vault AES-256-GCM + STREAM AEAD 4 MB Chunks, 96-bit Nonces (Counter + Last bit), 57B Header Peak RAM < 150 MB across 5 GB vaults. 0 bytes buffered to disk. Reordering, chunk truncation, ciphertext splicing, MITM tampering.
02. Virtual Filesystem Decrypted Overlay Map + Direct Re-encrypt Client-side SHA-256 path mapping, ephemeral session keys Zero disk persistence for plaintext modifications until explicit re-encrypt. Local storage forensic scraping, untrusted browser extension inspection.
03. Duress Decoy Vaults Dual AES-GCM Envelopes (`V3_FLAG_DURESS`) Distinct salt, IV, and 128-bit authentication tags per envelope Ciphertext indistinguishable from pseudorandom noise ($IND\text{-}CPA$). Coercion, border crossing searches, forensic proof of undisclosed data.
04. Polyglot Camouflage Steganographic Media Framing + Sliding Detector JPEG `0xFF 0xD9`, PNG `IEND`, MP4 `moov` marker detection Valid media stream prepended; unauthenticated vault silently bypasses parser. Deep packet inspection (DPI), automated media scanners, file type audits.
05. Vault Health & Salvage Fault-Tolerant AEAD Chunk Verification Per-chunk GCM tag verification, 16-byte isolation window Isolated chunk buffers. Corrupted blocks dropped; valid blocks rescued. Bit-rot, partial disk sector failure, incomplete download streams.
06. Cinema & Audio Dock In-Browser Web Cryptography + Object URL Revocation Ephemeral Blob URLs, MediaSource Extensions (MSE) Immediate `URL.revokeObjectURL()` on stop or modal close. Zero RAM leaks. DOM memory extraction, cross-origin resource leakage.
07. Passwords & Auto-Lock CSPRNG Diceware + Buffer Zeroization `crypto.getRandomValues()`, Shannon Entropy ≥ 77 bits, 5–60 min timer TypedArray `.fill(0)` on all key buffers immediately upon lock. Post-session memory dumps, cold-boot RAM attacks, unattended workstation snooping.
08. Key Derivation & 2FA PBKDF2-SHA512 + Keyfile Entropy Mixing 600,000 to 2,400,000 iterations, 32-byte salt, SHA-256 keyfile digest Hardware-bound key derivation. High time-memory cost. High-performance GPU cluster dictionaries, ASIC parallelized brute force.
09. Mobile Streaming Multi-Tier FSA / OPFS / Service Worker Pipeline 4 MB backpressure streams, transferable ArrayBuffers Strictly bounded peak memory < 150 MB on Android Chrome & iOS Safari. Mobile OS low-memory termination (OOM kill), multi-gigabyte upload traps.
