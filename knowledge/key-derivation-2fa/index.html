Key Derivation & 2FA Keyfiles

⏱️ 7 min read 🛡️ 600,000 – 2,400,000 Iterations 🗝️ SHA-256 Keyfile Mixing

When an adversary steals an encrypted file, they can mount offline brute-force or dictionary attacks using massive GPU clusters. Without a computationally demanding key derivation function, an attacker can test millions of passwords per second. ZevSafe implements High-Work-Factor PBKDF2-SHA512 Tiers up to 2.4 million iterations combined with Physical Hardware Keyfiles (2FA).

🟢 Simple User Guide

Hardening Your Vault in Seconds

STEP 01

Select Your Security Tier

Under "Advanced Security Options", choose your key derivation tier:
• Standard (600,000 rounds): Optimal for mobile phones and fast unlocking (~0.3s).
• Hardened (1,200,000 rounds): High security for personal laptops (~0.7s).
• Paranoid (2,400,000 rounds): Maximum defense for cold backups and financial records (~1.5s).

STEP 02

Attach a Physical Keyfile (2FA)

Drop any existing file—such as a specific photo on your USB flash drive, a music track, or a randomly generated binary key. That file becomes a physical second factor.

STEP 03

Unlocking Requires Both Factors

To unlock the vault, you must provide both the correct passphrase and the exact keyfile. Even if an attacker learns your password, they cannot decrypt a single byte without the physical keyfile!

⚠️
Important: Do not modify or edit your keyfile! Changing even a single pixel or character will alter its cryptographic checksum and prevent vault decryption. Keep safe backups of your keyfile on an offline flash drive.
🔵 Technical Specification

PBKDF2-SHA512 Derivation Algorithm

Key derivation is executed client-side using the native W3C Web Cryptography API (SubtleCrypto). The algorithm employs a 32-byte CSPRNG salt and 512-bit HMAC digest:

WebCrypto PBKDF2 Call 
// js/stream-crypto.js: Native PBKDF2-SHA512 Key Derivation
async function deriveVaultMasterKey(passwordBytes, saltBytes, iterations = 600000) {
    // 1. Import raw passphrase bytes
    const baseKey = await crypto.subtle.importKey(
        "raw",
        passwordBytes,
        { name: "PBKDF2" },
        false,
        ["deriveKey"]
    );

    // 2. Derive 256-bit AES-GCM Master Encryption Key
    const masterKey = await crypto.subtle.deriveKey(
        {
            name: "PBKDF2",
            salt: saltBytes,
            iterations: iterations, // 600k, 1.2M, or 2.4M
            hash: "SHA-512"
        },
        baseKey,
        { name: "AES-GCM", length: 256 },
        false,
        ["encrypt", "decrypt"]
    );

    return masterKey;
}

Physical Keyfile Entropy Mixing

When a keyfile is provided, ZevSafe computes its SHA-256 digest and concatenates it directly with the passphrase bytes before key derivation:

📐
$$\text{Digest}_{\text{KF}} = \text{SHA-256}(\text{KeyfileBytes})$$ $$\text{Password}_{\text{eff}} = \text{UTF-8}(\text{Passphrase}) \,\|\, \text{Digest}_{\text{KF}}$$ $$\text{MasterKey} = \text{PBKDF2-SHA512}(\text{Password}_{\text{eff}},\, \text{Salt}_{32},\, \text{Iterations},\, 256)$$
JavaScript 2FA Entropy Mixer 
// Mix password string with keyfile binary digest
async function mixPasswordWithKeyfile(passphraseStr, keyfileBuffer) {
    const passBytes = new TextEncoder().encode(passphraseStr);
    if (!keyfileBuffer) return passBytes;

    // Hash keyfile with SHA-256
    const keyfileHash = await crypto.subtle.digest("SHA-256", keyfileBuffer);
    const keyfileHashBytes = new Uint8Array(keyfileHash);

    // Concatenate into combined buffer
    const combined = new Uint8Array(passBytes.length + keyfileHashBytes.length);
    combined.set(passBytes, 0);
    combined.set(keyfileHashBytes, passBytes.length);

    return combined;
}

Hardware & GPU Brute-Force Cost Modeling

Modern high-end GPUs (e.g. NVIDIA RTX 4090) achieve ~2.5 million SHA-512 hashes per second. With 2,400,000 iterations:

Adversary Hardware Hash Rate Keys Tested / Second (2.4M Tier) Cost to Test 1 Billion Passwords
Single RTX 4090 GPU 2,500,000 H/s ~1.04 attempts / sec 30.5 years ($14,000 in electricity)
8x RTX 4090 Rig 20,000,000 H/s ~8.33 attempts / sec 3.8 years ($112,000 in hardware/power)
With 2FA Keyfile Attached Infinite ($2^{256}$) 0 (Search space $2^{256}$ SHA-256) Mathematically Impossible
