Google Font Decoupling & CSP Air-Gap Hardening

Prior versions loaded web fonts from fonts.googleapis.com and fonts.gstatic.com. In cold-boot air-gapped environments, external CSS requests fail, triggering HTTP timeouts, layout shift (CLS), and telemetry leakage risks. In Phase 13, all external CDN dependencies were completely eliminated.

IEEE 802.3 CRC-32 Verification

Every bundled file is hashed with a 256-entry precomputed CRC lookup table: 

function computeCRC32(data) {
    let crc = 0xFFFFFFFF;
    for (let i = 0; i < data.length; i++) {
        crc = CRC_TABLE[(crc ^ data[i]) & 0xFF] ^ (crc >>> 8);
    }
    return (crc ^ 0xFFFFFFFF) >>> 0;
}

Direct USB Drive Writer (File System Access API)

Using the W3C File System Access API, ZevSafe can stream directory structures directly to a physical drive without creating an intermediate ZIP file:

Direct Drive Streaming Loop (js/usb-backup-kit.js) W3C FSA API 
const dirHandle = await window.showDirectoryPicker({ mode: 'readwrite' });
for (const file of files) {
    const parts = file.name.split('/');
    let currentDir = dirHandle;
    for (let p = 0; p < parts.length - 1; p++) {
        currentDir = await currentDir.getDirectoryHandle(parts[p], { create: true });
    }
    const fileHandle = await currentDir.getFileHandle(parts[parts.length - 1], { create: true });
    const writable = await fileHandle.createWritable();
    await writable.write(file.data);
    await writable.close();
}

Cross-Platform Zero-Config Launchers

Launch-ZevSafe-Windows.bat

Checks for python or py in PATH. If found, starts a local sandboxed 127.0.0.1:8080 HTTP server. If Python is absent, opens index.html directly via the default Windows browser.

Launch-ZevSafe-Mac-Linux.sh

Detects python3 or python, binds to 127.0.0.1:8080, launches the default browser with open / xdg-open, and falls back cleanly to file URIs.

Security & Portability Invariants

  • Zero Network Dependency: The exported USB kit makes 0 network calls, fetches 0 CDNs, and transmits 0 telemetry.
  • Universal Compatibility: Any .zev container created on the air-gapped USB vault decrypts seamlessly on the web app, Android app, or PC desktop scripts.
  • Cryptographic Integrity: SHA-256 and IEEE 802.3 CRC-32 checksums guarantee bit-level authenticity across all exported assets.
