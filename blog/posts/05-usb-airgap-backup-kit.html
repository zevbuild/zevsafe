1-Click USB Air-Gap Backup Kit: Portable Offline Vaults

How to create a self-contained, portable offline vault on a USB thumb drive that runs on any computer without an internet connection or software installation.

1. The Threat Model of Online Decryptors

What happens if you need to decrypt critical files 5 years from now, but:

  • The website hosting your encryption tool is down or acquired?
  • You are located in an off-grid location or emergency shelter with no internet connectivity?
  • You are using an air-gapped forensic workstation that is strictly forbidden from connecting to the web?

If your encryption software depends on an active internet connection or third-party CDNs to load, your data is effectively hostage to network availability.

🛡️ The Standalone USB Principle

ZevSafe's USB Air-Gap Backup Kit exports the complete web vault software, stylesheets, worker engines, documentation, and launchers into a single folder or ZIP archive directly on your USB drive. You own the software forever.

2. Step-by-Step: Exporting to a USB Flash Drive

Exporting your standalone kit takes less than 5 seconds:

  1. Insert your USB flash drive into your computer.
  2. In the ZevSafe top navigation, click Tools → USB Air-Gap Backup Kit (or click the USB icon in the sidebar).
  3. Choose your export method:
    • Option A: Direct USB Drive Writer (Recommended): Uses the W3C File System Access API (showDirectoryPicker). Select your USB drive root folder, and ZevSafe writes all 31 essential files and scripts directly to the flash drive.
    • Option B: Download Offline ZIP: Compiles a single ZevSafe-Offline-Vault-Kit.zip in browser memory and downloads it for manual extraction.

3. Pure-JS PKZIP Generator & Direct FSA Writer

Most web applications rely on large external packaging libraries. ZevSafe's generator (js/usb-backup-kit.js) is completely written from scratch:

Pure-JS PKZIP 2.0 Generator · Bitwise IEEE 802.3 CRC32
// Pure JavaScript ZIP generation conforming to PKZIP 2.0 specs
function computeCRC32(bytes) {
    let crc = 0xFFFFFFFF;
    for (let i = 0; i < bytes.length; i++) {
        crc = (crc >>> 8) ^ CRC32_TABLE[(crc ^ bytes[i]) & 0xFF];
    }
    return (crc ^ 0xFFFFFFFF) >>> 0;
}

It computes exact byte lengths, central directory records, and relative header offsets in volatile memory, outputting a 100% compliant archive readable by Windows Explorer, macOS Archive Utility, and Linux unzip.

4. Multi-OS Zero-Config Launchers (.bat & .sh)

Browsers enforce strict security restrictions on file:// URLs (such as disabling Web Workers or Service Workers in local files).

To provide a 1-click experience, the USB Air-Gap Kit includes two zero-config local launchers:

  • Launch-ZevSafe-Windows.bat: Automatically checks for Python or PowerShell on Windows, starts an ephemeral local HTTP server bound strictly to 127.0.0.1, and launches your default browser. Closing the command window terminates the server instantly.
  • Launch-ZevSafe-Mac-Linux.sh: Shell script for macOS and Linux utilizing built-in python3 -m http.server or direct browser fallback.

5. True Air-Gap: 100% Font & CDN Decoupling

Many "offline" web templates silently fail when disconnected because they attempt to load fonts from fonts.googleapis.com or icons from un-cached CDNs.

ZevSafe guarantees Zero Remote Dependencies:

  • All font rules specify high-DPI native system typography stacks (Inter, Outfit, system-ui, and JetBrains Mono).
  • All icons are inline vector SVGs compiled directly into HTML markup.
  • Zero external network requests are made, guaranteeing zero Cumulative Layout Shift (CLS 0.00) and 100% air-gap compliance.
