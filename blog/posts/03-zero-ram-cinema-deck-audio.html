Zero-RAM Cinema Deck & Floating Audio Dock: Media Streaming in Encrypted Vaults

Play private videos, audiobooks, and podcasts directly inside decrypted vaults without writing cleartext files to disk or exhausting device RAM.

1. The Problem with Playing Encrypted Media

In most cryptographic suites, if you have a 3 GB video file (e.g. .mp4 or .mkv) inside an encrypted container, you have to decrypt the entire 3 GB to your physical hard drive before your default video player (VLC, Windows Media Player) can read it.

This breaks operational security in two ways:

  1. Cleartext Exposure: The full video is now vulnerable on your disk in plain sight.
  2. Performance Bottleneck: Mobile devices (smartphones, tablets) often lack the free storage space or RAM to unpack a 3 GB file, resulting in browser crashes.

2. The Cinema Deck: In-Browser Video Player 4.0

ZevSafe solves this with an integrated, zero-exfiltration video playback environment known as the Cinema Deck:

  • When you click a video file inside Vault Explorer, ZevSafe extracts the stream directly into a local in-memory Object URL.
  • The custom Cinema Deck interface mounts with playback controls: play/pause, seek scrub bar, volume, playback speed (0.5x to 2x), and picture-in-picture.
  • Cinema Dark Mode: Dims background UI elements to 0% opacity, providing a focused theater viewing experience without leaving the browser tab.

3. The Persistent Floating Audio Mini-Player

For music, podcasts, lecture recordings, and audiobooks, you rarely want to sit on a static modal. You want the audio to keep playing while you browse other folders, read documents, or organize files.

ZevSafe features a Floating Audio Mini-Player Dock:

  1. Click on any audio file (.mp3, .m4a, .wav, .ogg, .flac, .aac).
  2. Click the Dock Mini-Player button in the top right.
  3. The player minimizes into a sleek cybernetic dock pinned to the bottom of the screen.
  4. You can freely navigate directories, open folders, view photos, and edit text documents while audio continues uninterrupted.
  5. The mini-player dock provides compact play/pause, track progress bar, track title, and an expand toggle to restore the full audio interface.

4. Zero-RAM Streaming Architecture & Blob Revocation

How does ZevSafe prevent memory exhaustion when you preview multiple video or audio tracks?

🛡️ The URL Revocation Invariant

Whenever a media file is closed or a new track is selected, ZevSafe immediately invokes URL.revokeObjectURL(activeMediaUrl) and unbinds the <video> or <audio> element source. This signals the browser's V8 engine to immediately garbage-collect the underlying buffer, preventing cumulative RAM bloat.

JavaScript Architecture · Media Teardown Hook
function closeMediaPlayer() {
    const videoEl = document.getElementById('vault-video-player');
    if (videoEl) {
        videoEl.pause();
        videoEl.removeAttribute('src'); // Unbind media source
        videoEl.load();
    }
    
    // Explicitly release volatile blob URL from browser memory
    if (currentMediaBlobUrl) {
        URL.revokeObjectURL(currentMediaBlobUrl);
        currentMediaBlobUrl = null;
    }
}

5. Supported Audio & Video Formats

All formats natively supported by modern Chromium, WebKit, and Gecko browser engines can be played with zero third-party codecs or plugin installations:

  • Video: MP4 (H.264 / AAC), WebM (VP8 / VP9 / Opus), Ogg Theora.
  • Audio: MP3, AAC, M4A, Ogg Vorbis, Opus, WAV, FLAC.
