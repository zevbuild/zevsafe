How to Encrypt Files & Folders Using ZevSafe: Complete Step-by-Step Guide

1. The 3-Step Micro-Flow Overview

ZevSafe was engineered to remove technical friction from encryption. The entire encryption pipeline follows a simple mental model:

⚡ Core Mental Model

[ 1 📁 Select Folder or Files ] → [ 2 🔑 Choose Password or Key ] → [ 3 🛡️ Download Encrypted .zsafe ]

2. Step 1: Selecting Folders or Files

Open zevsafe.pages.dev in your web browser. In the Lock Any Folder card:

  • To Lock a Full Folder: Click 📁 Browse Folder to launch your operating system's directory picker. ZevSafe recursively reads all subfolders and files while preserving their relative paths.
  • To Lock Multiple Files: Click 📄 Browse Files to select individual documents, photos, or media files.
  • Drag and Drop: Drag any folder or files directly into the purple drop zone.

Once selected, the drop zone updates instantly to show the folder name, total file count, and uncompressed byte size.

3. Step 2: Choosing or Generating a Passphrase

Your passphrase is the cryptographic root of your vault. Enter your password in the passphrase field:

  • Real-Time Entropy Meter: The dynamic meter evaluates bit entropy, dictionary resistance, and character distribution as you type.
  • 1-Click Diceware Generator: Click the ⚡ Generate button to instantly produce a 6-word CSPRNG Diceware passphrase (e.g. correct-horse-battery-staple-beacon-glory). This provides over 77 bits of pure entropy, making brute-force attacks mathematically impossible.

4. Step 3: Optional Hardware Keyfile 2FA

Want mathematical protection even if someone discovers your password? Enable Keyfile 2FA:

  1. Click the 🔑 Use Keyfile (Optional 2nd Factor) toggle pill to expand the keyfile section.
  2. Click Select Keyfile to bind any local file (such as a favorite JPEG photo, PDF, or random MP3) as an indispensable second factor.
  3. Alternatively, click ⚡ Generate 512-bit Keyfile to download a cryptographically random 64-byte keyfile.

During derivation, ZevSafe computes MasterKey = DerivedKey ⊕ SHA-256(Keyfile). Without this physical file, the vault cannot be decrypted even with the correct password.

5. Step 4: Selecting a Security Defense Tier

Click ⚙️ Advanced Security Options to configure your Key Derivation Function (KDF):

  • Standard Security (600,000 PBKDF2 Rounds): Default setting. Derives keys in ~0.2s with zero UI lag while providing 6× the OWASP benchmark.
  • Hardened Security (1,200,000 Rounds): 12× baseline for multi-year cold storage.
  • Maximum Security (2,400,000 Rounds): Maximum resistance against distributed GPU/ASIC clusters.
  • Ultra Security (RFC 9106 Argon2id 64MB): Memory-hard KDF that forces attackers to allocate 64 MB of RAM per password guess, defeating parallel GPU arrays.

6. Step 5: Generating a Cold-Storage Recovery Sheet

Before locking your vault, click ⬇️ Download Sheet or 🖨️ Print Sheet:

ZevSafe generates a physical Paper-Safe Emergency Sheet featuring your formatted 32-byte salt fingerprint and a high-density optical QR code. Store this paper sheet in a physical safe or offline lockbox.

7. Step 6: Encrypting and Downloading Your .zsafe Vault

Click 🔒 Encrypt & Download:

  1. The elastic multi-worker pipeline activates, displaying real-time progress for file compression, chunk encryption, and manifest assembly.
  2. Your browser downloads the completed, authenticated container: <foldername>.zsafe.
  3. You can now safely store this .zsafe file on Google Drive, Dropbox, USB flash drives, or external hard drives without cloud providers being able to read your files.
