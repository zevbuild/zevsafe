Phase 08 · Up Next

Argon2id WASM Memory-Hard KDF

Architectural Overview

Provides memory-hard password derivation via a lightweight compiled WebAssembly runtime to render GPU and ASIC cluster attacks economically infeasible.

Cryptographic & System Invariants

Standard Argon2id (RFC 9106)
Memory Cost (m) 64 MB (65,536 KiB)
Time Cost (t) 3 Iterations
Parallelism (p) 4 Lanes
Binary Footprint < 35 KB gzipped WASM
Fallback Strategy PBKDF2-SHA512 (600k rounds)
🔒 Zero-Network Guarantee: All runtime modules and architecture specifications are 100% precached in the browser cache and execute entirely in client-side RAM.
